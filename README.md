# Kabel — Releases

This repo hosts only compiled release binaries for [Kabel](https://kabel.minhanh1409.dev),
a cross-platform connection manager (SSH, Telnet, RDP, VNC, FTP, Serial).

**No source code lives here.** The source is closed and private. This repo
exists solely as a public download point for release artifacts via
[GitHub Releases](../../releases).

See [LICENSE](LICENSE) for terms covering downloaded binaries.
